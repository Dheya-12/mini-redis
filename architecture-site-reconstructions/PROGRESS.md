# Architecture site reconstructions — progress

Clean-room Next.js + TypeScript reconstructions, processed strictly one site at a time.
Each site lives in `NN-slug/` and ships as `zips/NN-slug-nextjs.zip` (complete source, no `node_modules`;
`npm install && npm run dev` / `npm run build`). Autonomous decisions are logged in [`DECISIONS.md`](./DECISIONS.md);
each project has its own `README.md` and measured `FIDELITY.md`.

Visual validation = pixel diff (pixelmatch, threshold 0.1) against the live site at 1440×900, 1024×768 and 390×844
(touch), plus key interaction states. Each project's `FIDELITY.md` lists its frame set (Loam House: every chapter rest
position and midpoint; Thirdway: every viewport step of 13 representative routes) and explains any frame over the gate.
Gates: ≤1.0% per static frame, ≤1.5% per motion frame.
