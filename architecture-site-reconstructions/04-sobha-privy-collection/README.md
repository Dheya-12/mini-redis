# Sobha Privy Collection — clean-room Next.js reconstruction

Reconstruction of [sobha-privy-collection.com](https://sobha-privy-collection.com/) (website by Vide Infra) as a
Next.js 16 App Router project. Five routes are statically generated: the home page, `/location` (the 3D map), and
the three policy pages (`/privacy-policy`, `/privacy-policy-uk-eu`, `/data-protection-policy`).

```bash
npm install
npm run dev        # http://localhost:3000
npm run build && npm start
npm run lint && npm run typecheck && npm test
```

## Typefaces

TT Commons Pro, TT Ramillas (TypeType) and Altesse Std (Typekit) are commercial and are **not** included. With a
licence, put the files in `public/fonts/licensed/` (git-ignored) under the names `src/app/fonts.css` expects, and
they are used automatically. Without them, the text falls back to open-licence faces, metric-matched to the originals
(Outfit, Bodoni Moda and Pinyon Script; SIL Open Font License; `public/fonts/fallback/`).

## How it is built

The public markup and stylesheets are captured as data; all behaviour is new code.

| Path | What it is |
|------|------------|
| `src/content/pages/*.json` | One file per route: the page's server-rendered markup as a compact element tree (`[tag, props, ...children]`), with media pointing at `/media/*` and the Kinescope films replaced by local `<video>` loops |
| `src/content/chrome.json` | Skip link, preloader screens, cookie bar, rotate-device message |
| `src/styles/site.css` | The original's stylesheets, filtered to the rules these pages use and scoped per route (generated by `tools/extract-styles.mjs`) |
| `src/behaviours/parallax/` | The scroll-linked animation engine (keyframes relative to screen and element, eased segments, section visibility, phone smoothing) and the 42 named animation patterns the markup refers to |
| `src/behaviours/stickySlider.ts` | The horizontal "Expansive spaces" slider pinned while the page scrolls |
| `src/behaviours/smooth.ts` | Lenis smooth scrolling with the original's "gravity wells" (the scroll slows near section points), in-page links |
| `src/behaviours/reveal.ts`, `transition.ts`, `split.ts` | Scroll reveals (titles by character, text by line, fades and slides) driven by the stylesheet's transition classes |
| `src/behaviours/preloader.ts` | The intro screen (the monogram drawn as media loads) and the page-change screen |
| `src/behaviours/navigation.ts` | Page changes without reloads: the preloader screen by default, a fade for the policy tabs |
| `src/behaviours/header.ts` | Header theme per section, top state, hiding |
| `src/behaviours/contentAnimation.ts` | Content switchers: the three worlds' titles, the location cards, the quotes |
| `src/behaviours/modal.ts`, `menu.ts` | The menu and the location modals (open/close transitions, focus, Escape, address hash); the menu's pointer-following chapter list |
| `src/behaviours/map.ts`, `pointer.ts`, `cookies.ts`, `iframeSize.ts`, `films.ts`, `appear.ts` | Map pins and phone cards, the quotes cursor and the footer's masked line, cookie consent, film sizing and playback, lazy images |
| `src/gl/threeWorlds.ts`, `handpicked.ts`, `location.ts` | The three WebGL scenes (three.js): the three worlds on a ring with the camera zooming into each; the Handpicked gallery; the 3D map of Dubai with its camera flight, volumetric clouds and pins |
| `tools/extract-content.mjs`, `tools/extract-styles.mjs` | Build-time extractors that produced `src/content`, `public/media`, `public/webgl` and `src/styles/site.css` |
| `tools/visual-diff/` | Capture, pixel-diff and interaction harness used for `FIDELITY.md` |

Libraries: three.js 0.179.1 (the original's r179), Lenis 1.3.21, GSAP 3.14.2 (its ticker drives Lenis), Splitting
1.1 (MIT) for character and line splits. Next 16.3.6, React 19.2, Tailwind CSS 4 (limited to `src/components`; the
original's own CSS framework styles the pages).

## Differences from the live site

- **Films** are self-hosted MP4 loops (1080p, muted), not Kinescope players.
- **Page changes** use the same two transitions on the Next.js router. A page reached through the preloader screen
  starts at the top: Barba's history scroll restoration is not reproduced.
- **Analytics, reCAPTCHA and tracking** are removed. The cookie bar records the choice but loads nothing.
  `utm_*` parameters are kept for the session, as on the original.
- **Typefaces**: see above.

All photographs, films, the 3D model and copy belong to Sobha Realty and their authors and are included only so the
reconstruction can be compared with the original.
